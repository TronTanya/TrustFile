# TrustFile — контроль целостности файлов

TrustFile вычисляет SHA-256 файлов, сохраняет эталонный манифест и при повторной
проверке показывает, какие файлы совпадают, изменились, отсутствуют или добавлены.
Приложение работает локально и без интернета.

> Совпадение хеша означает только то, что загруженные байты совпадают с эталонным
> отпечатком. Это не доказывает, что файл безопасен, подлинен или не содержит
> вредоносного кода. Манифест не имеет цифровой подписи и может быть изменён.

## Установка и запуск

Требуется Python 3.11 или новее.

### Windows (PowerShell)

```powershell
cd TrustFile
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Если PowerShell запрещает запуск скриптов, выполните один раз
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или активируйте окружение
из командной строки (cmd): `.venv\Scripts\activate.bat`.

### macOS / Linux

```bash
cd TrustFile
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере по адресу http://localhost:8501.
Остановить сервер: `Ctrl+C` в терминале.

### Тесты и эксперимент

```bash
python -m pytest
python experiments/benchmark.py
python experiments/benchmark.py --repeats 21 --csv experiments/results/benchmark.csv
```

## Возможности

- **Создать эталон.** Загрузка до 50 файлов (до 20 МБ каждый, до 100 МБ на набор),
  вычисление SHA-256 по блокам, таблица «имя — размер — хеш», просмотр и копирование
  полного хеша, скачивание манифеста JSON.
- **Проверить файлы.** Загрузка манифеста (до 1 МБ) и текущего набора, строгая
  проверка манифеста, статусы «Совпадает», «Изменён», «Отсутствует», «Добавлен»,
  экспорт в CSV (UTF-8 с BOM) и автономный HTML-отчёт.
- **Сравнить с известным SHA-256.** Проверка одного файла по отпечатку из
  независимого источника.
- **Демонстрационный режим.** Встроенные эталонный и изменённый наборы (ZIP),
  демо-манифест и кнопка демонстрационной проверки, результаты которой отделены
  от пользовательских.
- **О проекте.** Назначение, принцип работы, гипотеза и ограничения.

## Формат манифеста

```json
{
  "schema_version": 1,
  "app": "TrustFile",
  "app_version": "1.0.0",
  "hash_algorithm": "SHA-256",
  "created_at": "2026-10-11T12:00:00Z",
  "file_count": 1,
  "files": [
    {"name": "отчёт.txt", "size": 84, "sha256": "<64 шестнадцатеричных символа>"}
  ]
}
```

Записи отсортированы по имени. Манифест не содержит путей и содержимого файлов.
При загрузке отклоняются: некорректный JSON, повторяющиеся ключи, неизвестная
версия схемы, другой алгоритм, несоответствие `file_count`, повторяющиеся имена,
отрицательные или нецелые размеры, хеши не из 64 шестнадцатеричных символов,
более 50 записей, имена с путями, `..`, разделителями, нулевыми байтами
и управляющими символами.

## Безопасность и приватность

- Загруженные файлы хранятся только в памяти сеанса, не записываются на диск
  и никогда не исполняются.
- Имя файла используется только как идентификатор, а не как путь.
- Манифест рассматривается как данные: пути из него не открываются.
- Весь пользовательский текст в HTML экранируется; в CSV значения, начинающиеся
  с `=`, `+`, `-`, `@`, табуляции или перевода строки, предваряются апострофом.

## Ограничения

- Проверяется только целостность байтов; антивирусной проверки нет.
- Авторство не устанавливается; манифест не подписан.
- Если злоумышленник изменит и файл, и манифест, подмена не будет обнаружена:
  храните эталон отдельно.
- Сопоставление — по точному имени с учётом регистра; переименование выглядит
  как «Отсутствует» + «Добавлен».
- Поддерживаются плоские наборы файлов; каталоги и архивы не разбираются.
- Надписи внутри стандартного виджета загрузки Streamlit («Upload», «20MB per file»)
  выводятся самим Streamlit на английском языке.

## Демонстрация за три минуты

1. **Создание эталона (≈40 с).** Откройте «Проверить файлы» → «Демонстрационный
   режим», скачайте «Эталонный набор (ZIP)» и распакуйте. На вкладке «Создать эталон»
   загрузите три файла, покажите таблицу хешей и скачайте эталонный манифест.
2. **Изменение (≈30 с).** Откройте `отчёт.txt` в блокноте, замените одну цифру
   (например, 42 → 43) и сохраните. Удалите `данные измерений.csv` из набора
   и создайте новый файл `приложение.txt`.
3. **Проверка (≈40 с).** На вкладке «Проверить файлы» загрузите манифест и текущий
   набор, нажмите «Проверить».
4. **Результаты (≈40 с).** Покажите сводку и таблицу: «Совпадает» (`readme.txt`),
   «Изменён» (`отчёт.txt`), «Отсутствует» (`данные измерений.csv`),
   «Добавлен» (`приложение.txt`). Раскройте полный хеш и покажите, что изменение
   одного символа полностью меняет отпечаток.
5. **Отчёт (≈30 с).** Скачайте HTML-отчёт и откройте его в браузере без сервера.

Если времени мало, вместо шагов 1–3 нажмите «Запустить демонстрацию»: те же
статусы будут получены на встроенных файлах.

## Эксперимент

`experiments/benchmark.py` создаёт детерминированные синтетические данные
(1 КиБ, 64 КиБ, 1 МиБ, 16 МиБ), изменяет один бит одного байта, сравнивает хеши
и измеряет медианное время хеширования (`perf_counter`, по умолчанию 15 повторов).
Время зависит от компьютера и среды выполнения. Различие хешей на нескольких
примерах — наблюдение, а не доказательство стойкости SHA-256 к коллизиям.
